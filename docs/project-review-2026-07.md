# 项目复盘与优化记录（2026-07）

本次复盘对四个模块（板块扫描 / 决策看板 / 缠论分析 / 大盘复盘）的分析逻辑、金融口径和视觉体系做了一次全面诊断，并完成整改。诊断结论均以代码位置与真实缓存数据为证据，不是主观印象。

## 一、诊断结论

### A. 决策看板因子体系（问题最集中）

| # | 问题 | 证据 | 整改 |
|---|------|------|------|
| A1 | 明细页与轮动页使用两套归一化，同一板块在两处显示不同的评分与信号档位 | `build_decision_sector` 自建 ad-hoc 归一 vs 轮动页截面 z-score | 明细页改为复用当日轮动缓存中的截面结果，两处口径强一致 |
| A2 | 明细页 MACD 标准化恒为 0：对单元素列表做 z-score | 缓存实证：半导体 raw=0.09→norm=0.0；消费电子 raw=100.02→norm=0.0 | 随 A1 消除 |
| A3 | 明细页动量归一化把 20 日涨幅与自身 1..20 日收益阶梯比较，出现"20 日涨 12% 却得 -0.45 分" | 缓存实证（半导体 2026-06-17） | 随 A1 消除 |
| A4 | 轮动页广度因子被硬置为 0，却占综合分 20% 权重，并伪造置信度（全员 conf=1.0） | 缓存实证：全部板块 breadth=0、confidence=1.0 | 广度缺失时权重重分配（趋势 0.40/动量 0.30/资金 0.30），置信度重定义为数据完备度 |
| A5 | MACD 柱未按价格水平归一，ETF（~3 元）与行业指数（~11000 点）混入同一截面；`macd()` 两位小数舍入把 ETF 的 MACD 抹成 0 | 轮动全部走 ETF 代理行情 | `macd()` 不再舍入；评分用 `MACD柱/收盘价×100`（百分比口径，跨标的可比） |
| A6 | 动量组两因子截面同质：`RS20 = ret20 − 基准常数`，z-score 后与 `ret20` 完全相同，0.45/0.55 权重实际是单因子 | 数学恒等式 | 评分改为 `z(ret20)×0.6 + z(ret60)×0.4`；RS20 保留为展示列 |
| A7 | 门控双重惩罚且展示矛盾：资金背离已在综合分里扣分，又强制降级信号档位，出现"综合分 +0.20 却标看空、夹在两个中性之间" | 缓存实证（光学光电子 2026-07-01） | 信号档位一律由综合分决定；SG4/SG5 降级取消，改为警示标签 + 置信度折减 |
| A8 | 资金流单位混乱（AKShare 为元、WeStock 兜底为万元，直接混入同一截面）；明细页资金流用符号函数归一，净流入 1 元也得满分 1.0 | 代码审查 | 净额统一换算为亿元（展示）；评分改用主力净流入净占比 %（占成交额比例，跨板块规模可比）；无净占比的兜底数据只展示不评分 |
| A9 | 拥挤度因子计算、归一、展示俱全，但综合分权重为 0，方向语义未定义 | 代码审查 | 明确为风险因子：不进综合分；高换手 + 强动量时输出 `RISK3:交易拥挤` 警示并折减置信度 |
| A10 | 价格区间基准漂移：有的板块报 ETF 价格、有的报指数点位（不可交易）；盈亏比恒等于 1.33 无信息量 | 缓存实证（半导体 3.57 vs 消费电子 11394） | 价位区间一律基于可交易 ETF 代理并标注基准标的；盈亏比改为止损/目标相对幅度 % |
| A11 | 个股页 `macd_norm = macd/(|macd|×3)` 恒等于 ±0.333；RSI 线性加分无超买惩罚 | 代码审查 | MACD 改按价归一（±0.5% 饱和）；RSI 分段：45→70 加分、>75 超买递减、<30 超卖不给负满分 |

**新口径摘要**

- 组权重：趋势 0.30 / 动量 0.25 / 资金 0.25 / 广度 0.20；缺数据的组不按 0 分占位，而是权重按比例重分配。
- 置信度 = 数据完备度：基础 0.40 + ADX 有效 0.15 + 真实资金流 0.25 + 真实广度 0.20；背离警示 −0.15、拥挤警示 −0.10，下限 0.20。
- 信号档位阈值不变（±0.25 / ±0.55 五档），但档位只由综合分决定。
- 决策缓存升级为 `decision_v2_*`，旧口径缓存自动失效。

### D. 视觉体系

诊断：四套前端各自维护调色板，涨跌色共有 4 套并存（tokens 色 / 抽屉图 `#e1322f,#008f5d` / 状态栏暗色遗留 `#ff6b68,#4fd6a0` / canvas 硬编码）；缠论页令牌漂移且未加载 webfonts；五个页面五个品牌身份；大盘信号灯用西式"绿=可进攻"，与全站 A 股涨红跌绿相反。

整改：

1. 新建 `shared/tokens.css`（唯一调色板来源：paper 色系 + 涨红跌绿 + 服务状态色 + 图表辅助色 + 热力色带端点 + 字体/间距/圆角）和 `shared/ui.css`（统一顶栏、品牌、模块导航、按钮、卡片、tier 徽章、涨跌工具类）。五个页面全部引入。
2. 品牌统一：红底 serif 单字方块（板/缠/决/复/帮）+ 主标题「A股分析终端」+ 模块副标；`<title>` 统一为「模块名 · A股分析终端」；品牌链接统一指向 `/sector`；帮助页补上模块导航。
3. 硬编码色收敛：扫描页抽屉图/状态栏、决策页 canvas（蜡烛/均线/网格）全部改走 tokens；热力图图例与色块共用 `--heat-*` 端点。
4. 信号灯语义统一（已确认）：可进攻=红（`--up`）、需观察=金（`--gold`）、偏防守=绿（`--down`）；后端 green/yellow/red 键名保留，仅展示层重映射。服务健康状态改用独立的 `--ok/--warn/--err`，不再复用涨跌色。
5. 数字与判定统一：locale zh-CN、正数带 +、涨跌判定统一为 >0/<0、数字一律 mono tabular；市场类型徽章不再使用涨跌语义色。

## 二、已知边界与后续方向

- 资金净占比依赖 AKShare 板块资金流接口；接口不可用时资金组不参与评分（权重重分配），这是有意的"诚实降级"。
- 轮动广度仍无真实数据来源（拉全部成分股代价过高）；明细页的涨跌家数比、站上 MA20/60 占比仅作展示。
- 缠论买卖点为规则口径（背驰 + 中枢突破回抽），未做历史胜率统计；历史回测、信号统计、可配置因子权重仍是后续方向。
